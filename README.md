A tiny pure-stdlib Python program that writes a two-line explanation of a traffic jam for a 10-year-old: line 1 explains it in one vivid sentence through a single analogy (a river of metal fish), and line 2 says in one sentence what the analogy maps and what it leaves out.

## Run it

```sh
python3 main.py
```
